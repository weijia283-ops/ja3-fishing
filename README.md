# Ja3 — Lure Fishing Journal

一个关于路亚、溪流与探索的个人网站。

## 网站内容
- 首页：Ja3 品牌视觉与溪流主题
- 河流日志：出钓故事与水情观察
- 鱼种图鉴：鳜鱼、翘嘴、马口、虹鳟
- 装备库：常用路亚装备与钓组
- 关于 Ja3：从嘉陵江上游出发的个人记录

## 在线预览
启用 GitHub Pages 后，网站地址为：
https://weijia283-ops.github.io/ja3-fishing/

## 发布方式
仓库 Settings → Pages → Build and deployment：
1. Source 选择 Deploy from a branch
2. Branch 选择 main
3. Folder 选择 /(root)
4. 点击 Save

首页文件为根目录下的 `index.html`。
